# Fornax Lucifer

Приложение для Windows и библиотека раскладок для макропада **MacroPad Lucifer** — 9 клавиш, ручка-энкодер,
цветной экран и 23 светодиода. Приложение само переключает слои под открытую программу, подсказывает готовые
раскладки и обновляется само.

> Проект в разработке (бета). Раскладки из библиотеки пока не проверены на живых программах — пометка `tested: false`.

## Скачать

**[Последняя версия → Releases](https://github.com/fornax-works/lucifer-layers/releases/latest)** — файл `Fornax-Lucifer-Setup-X.Y.Z.exe`.

- Windows 10 / 11, права администратора не нужны (ставится в `%LOCALAPPDATA%\Programs\Fornax Lucifer`).
- Во время установки из интернета докачивается интерфейс (PySide6, около 200 МБ) — пара минут.
- Установщик пока без цифровой подписи: если Windows SmartScreen предупредит — «Подробнее» → «Выполнить в любом случае».
- Новую версию можно ставить прямо поверх, удалять старую не нужно. Дальше приложение обновляется само.
- Прошивка для пада лежит внутри установщика — приложение предложит обновить пад, когда выйдет новая.

## Что умеет

**Слои и программы**
- Три режима: **Авто** (слой меняется вместе с активной программой), **Закреплён**, **Общий**.
- Слева — программы, найденные на компьютере: нажал — видно её слой и текущие макросы или предложение скачать шаблон.
- Шаблоны из библиотеки ставятся в один клик и правятся под себя («своя версия» не затирается обновлением).

**Действия на клавишах и ручке**
- Сочетание клавиш, медиа, смена слоя; на одной клавише — нажатие, удержание и двойное нажатие.
- Макрос из шагов (сочетание, текст, пауза, медиа) — можно записать с клавиатуры кнопкой «● Записать».
- Текст, в том числе по-русски (печатает приложение).
- **Запустить** — программу, сайт, файл или папку; если программа уже открыта — её окно выходит вперёд.
- **Колесо мыши** на ручке или клавише: прокрутка, вбок, зум.
- Ручка: громкость активной программы, смена слоёв; удержание — шпаргалка всех клавиш поверх экрана.

**Экран и подсветка**
- Часы, кот с настроением (печатает, когда печатаешь вы), подписи клавиш, помодоро, мониторинг ПК, уведомления.
- 23 светодиода по периметру — эффекты и цвета.

**Надёжность**
- Настройки копируются в «Документы → Fornax Lucifer → Копии настроек» (последние 14 дней) и восстанавливаются сами.
- Копия настроек хранится и **в самом паде**: подключили к новому компьютеру — всё на месте.
- Удаление программы настройки не трогает.

## Приватность

- Какие программы у вас стоят, никуда не отправляется: каталог библиотеки скачивается целиком, совпадения ищутся на компьютере.
- Заголовок активного окна (для настроения кота) проверяется только в памяти, не пишется в журнал и не сохраняется;
  функцию можно выключить.
- Для кота считается только **количество** нажатий клавиш — что именно нажато, не читается и не сохраняется.
- Сеть: GitHub — напрямую или через CDN jsDelivr (каталог раскладок, обновления), при установке — PyPI (PySide6).
  Шрифты интерфейса пока грузятся с Google Fonts — в следующей версии будут встроены в приложение.

## Безопасность

- Каталог раскладок `index.json` и манифест обновлений `app/latest.json` подписаны **Ed25519**; публичные ключи вшиты
  в приложение — неподписанный или подделанный файл не примется.
- Каждый слой сверяется по SHA-256 из каталога, установщик обновления — по размеру и SHA-256 из подписанного манифеста
  и скачивается только с github.com.
- Слои — только данные (клавиши и подписи), никаких скриптов и команд.
- Секретные ключи хранятся у владельца офлайн и **никогда** не кладутся в репозиторий (`*.key` в `.gitignore`).

## Библиотека раскладок

Сейчас в каталоге: Adobe Photoshop, Adobe Premiere Pro, DaVinci Resolve, Blender, Autodesk Fusion, Figma,
KiCad (схема и плата), Visual Studio Code, Microsoft Excel, Discord, браузеры (Chrome, Edge, Brave).

Нужна раскладка для другой программы или нашли ошибку — [создайте Issue](https://github.com/fornax-works/lucifer-layers/issues/new).

### Формат слоя — `packs/<id>.json`

```jsonc
{
  "schema": 1,
  "id": "blender",                 // = имя файла; латиница в нижнем регистре, цифры, дефис
  "name": "Blender",               // название в приложении
  "layer": "BLENDER",              // имя слоя на экране пада, до 11 латинских символов
  "category": "3D",
  "exe": ["blender.exe"],          // для каких программ (нижний регистр)
  "version": 1,                    // увеличивать при каждом изменении
  "author": "Lucifer",
  "tested": false,                 // проверено ли на живой программе
  "keys": [                        // ровно 9, K1…K9: слева направо, сверху вниз
    { "label": "GRAB", "combo": "G", "desc": "Переместить" },
    { "label": "VOL+", "media": "vol+", "desc": "Громче" },
    { "none": true }
  ],
  "encoder": {                     // поворот влево, нажатие, поворот вправо
    "left":  { "label": "FRAME-", "combo": "Left",  "desc": "Кадр назад" },
    "press": { "label": "PLAY",   "combo": "Space", "desc": "Воспроизвести" },
    "right": { "label": "FRAME+", "combo": "Right", "desc": "Кадр вперёд" }
  }
}
```

- `label` — подпись на экране пада, до 8 латинских символов.
- `combo` — `Ctrl`, `Shift`, `Alt`, `Win` + клавиша: `A`…`Z`, `0`…`9`, `F1`…`F24`, `Space`, `Tab`, `Esc`, `Enter`,
  `Backspace`, `Delete`, `Home`, `End`, `PageUp`, `PageDown`, `Left` / `Right` / `Up` / `Down`, `Num 0`…`Num 9`,
  знаки ``- = [ ] \ ; ' ` , . /``. Пример: `Ctrl+Shift+Z`.
- `media` — `play`, `next`, `prev`, `stop`, `mute`, `vol+`, `vol-`.
- `{ "none": true }` — пустая клавиша.

## Что в репозитории

| Путь | Что это |
|---|---|
| `packs/` | раскладки, по файлу на программу |
| `index.json` + `.sig` | подписанный каталог (собирается из `packs/`) |
| `app/latest.json` + `.sig` | подписанный манифест последней версии приложения |
| `tools/` | сборка и подпись каталога (`build_index.py`) |
| [Releases](https://github.com/fornax-works/lucifer-layers/releases) | установщики приложения |

## Для владельца: выпуск

**Раскладки:** поправить `packs/*.json` (поднять `version`), затем

```
python tools/build_index.py --key ПУТЬ\к\lucifer_library.key
```

скрипт проверит все слои, соберёт `index.json` и подпишет его. Загрузить изменённые `packs/`, `index.json`, `index.json.sig`.

**Приложение:** локальным скриптом подписать `app/latest.json` ключом обновлений, создать релиз `vX.Y.Z` с установщиком,
затем загрузить `app/latest.json` и `app/latest.json.sig`. Сначала релиз, потом манифест — иначе приложения
увидят версию, которую ещё нельзя скачать.

## In English

Fornax Lucifer is the Windows companion app and layout library for the MacroPad Lucifer (9 keys, rotary encoder,
colour screen, 23 RGB LEDs). It switches layers per active program, offers ready-made layouts for popular apps, runs
programs, records macros, scrolls with the knob and keeps a backup of your settings on the pad itself. Download the
installer from [Releases](https://github.com/fornax-works/lucifer-layers/releases/latest). The layout catalog and
update manifest are Ed25519-signed; installed programs are matched locally and never uploaded. The interface is
Russian for now.
